# File-Backed Review Comments

**Started:** 2026-10-28
**Status:** Draft

## Summary

Save Local Review comment threads to `.local-review/<relpath>.review.json` so AI
agents can reply to, resolve and delete review comments by editing the files
directly, with the extension re-rendering changes live. Replaces the
copy-to-clipboard handoff.
